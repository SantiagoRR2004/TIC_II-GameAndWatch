# Game & Watch Green House

## Overview

This is a project for a subject called "Tecnologías de la Información y la Comunicación II" (Information and Communication Technologies II). It was made by a team of 3 people. The submission took place on Sunday, the 6th of February of 2022, and earned a grade of 10 out of 10 points.

## Project Summary

For this project we had to implement the a game using python. We used the Pygame library to recreate the game [Green House](https://en.wikipedia.org/wiki/List_of_Game_&_Watch_games#Green_House) from the Game & Watch series. [Here](https://www.youtube.com/watch?v=CS-JGLZpSIU) is a video of gameplay.
